# Alpha Studios

## Open the web app

**Live site:** https://realkinghrs.github.io/alpha-studios/

**Crew portal:** open the site, type `cryptex`, enter your PIN on the wheels, then enter the code emailed to you.

## Run it on your computer

You need Node.js 22. In this folder:

```bash
npm ci
npm run dev
```

Then open http://localhost:5173/alpha-studios/

To see the built site instead: `npm run build` then `npm run preview`, and open http://localhost:4173/alpha-studios/

More (going live, secrets, recovery): `docs/GO-LIVE.md` and `docs/RUNBOOK.md`.
